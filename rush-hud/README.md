# Nonchalant Rush HUD

Отдельное Windows-приложение для стрелок поверх видимой доски в задачах Chess.com. Устанавливается рядом с Tal HUD Mentality: отдельные appId, профиль, расширение и порт. На Windows работает официальный нативный Stockfish 19 Universal; на Mac/Linux для разработки — WASM Lite. Движок заранее запускается один раз; один поиск ограничен 100 / 250 / 600 мс, без проверки жертв на глубине 22. Стрелки рисует расширение прямо поверх доски сайта и пропускает клики. Смотреть в окно приложения во время решения не требуется. Автоматического выполнения ходов нет.

Установка описана в [QUICKSTART-WINDOWS.txt](QUICKSTART-WINDOWS.txt). Расширение Rush HUD нужно установить отдельно; расширение списка ходов Tal HUD сюда не подходит. Приложение копирует распакованную папку в стабильный userData, в том числе при запуске portable.

## Как поступает позиция

Расширение работает только на `https://[www.]chess.com/puzzles…` и читает DOM видимых фигур (`wc-chess-board`, `.piece.wk.square-51`). Решения задач, приватные внутренности сайта и сетевые ответы не читаются. Сторона решения по умолчанию определяется ориентацией доски; цвет можно задать вручную в расширении. Подключаться нужно после установочного хода соперника. Последующие ходы сопоставляются с легальными переходами. Неоднозначный переход считается новой позицией с ходом выбранной стороны.

Начальный снимок не содержит прав рокировки и en passant: приложение их не угадывает. Это ограничивает задачи на эти темы. Для точной ручной проверки есть полный FEN. После отслеженного двойного хода пешки поле en passant сохраняется.

При изменении фигур/ориентации старая стрелка снимается до следующего кадра. Расширение ждёт конца анимации и устойчивой расстановки, поэтому общий отклик включает примерно 200 мс при стандартной анимации Chess.com, бюджет поиска и транспорт. Ответ проверяется по вкладке, сессии, номеру запроса, positionId, текущей расстановке и легальности хода. При скрытой вкладке, потере связи или паузе стрелка исчезает. На ходе соперника поиск не запускается, если переход удалось проследить.

## Ограничения скорости и качества

Миллисекундный бюджет поиска не гарантирует мгновенную стрелку и правильное решение любой задачи. Даже сильный движок при коротком поиске может не увидеть глубокую комбинацию или предложить другой ход, который сайт не принимает. 90 задач за 5 минут — цель для проверки, не подтверждённый результат этой версии. Счёт включает ручные действия и все ходы комбинаций.

## Разработка

Из корня репозитория: `npm ci`, затем `npm --prefix rush-hud run setup`.

```sh
npm --prefix rush-hud run typecheck
npm --prefix rush-hud test
npm --prefix rush-hud run test:extension
npm --prefix rush-hud run smoke
npm --prefix rush-hud run benchmark -- 250 90
npm --prefix rush-hud run dist:win
```

Бенчмарк использует существующие CC0-позиции банка Lichess 2200–2800, подаёт все канонические позиции решения и считает совпадения с исходными ходами. Несовпадающие альтернативы не переоцениваются. Это не реальный прохождённый штурм. Результаты в `test-results/benchmark-250.json`; их нельзя интерпретировать как процент решённых задач на Chess.com.

Официальный Stockfish 19 Universal поставляется без изменений вместе с GPL, исходниками и документацией из официального архива. Сборка скачивает закреплённый архив и проверяет SHA256. WASM для разработки также поставляется без изменений отдельным процессом. [THIRD-PARTY.txt](THIRD-PARTY.txt).
