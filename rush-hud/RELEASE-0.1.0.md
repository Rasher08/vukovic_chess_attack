# Nonchalant Rush HUD 0.1.0 — Windows

Отдельное приложение для быстрых подсказок в задачах и тактическом штурме Chess.com. **Оранжевые стрелки появляются прямо поверх доски сайта**, пропускают клики и исчезают при смене позиции. Во время решения смотреть в окно приложения не требуется. Фигуры двигает пользователь.

- Установщик `Nonchalant-Rush-HUD-0.1.0-setup.exe` или portable без установки.
- Официальный нативный Stockfish 19 Universal для Windows x64, один прогретый процесс.
- Бюджеты поиска 100 / 250 / 600 мс; стандартно 250 мс. Полная задержка дополнительно включает анимации доски и транспорт.
- Свой appId, профиль и порт 18329. Tal HUD Mentality работает отдельно.
- В комплекте новое расширение **Nonchalant Rush HUD**. Старое расширение списка ходов Tal HUD для этого приложения не подходит.

## Как включить

1. Запустить setup или portable.
2. В приложении нажать **Папка расширения**, в Chrome/Edge открыть управление расширениями → режим разработчика → **Загрузить распакованное** и выбрать эту папку.
3. Открыть Chess.com → Задачи → Штурм, обновить вкладку. Подключаться после установочного хода соперника.
4. Нажать **Копировать ключ** в приложении, вставить ключ в расширение Rush HUD и подключить текущую вкладку. После перезапуска приложения ключ меняется.
5. Авто определяет цвет по ориентации доски; можно задать цвет вручную.

Пять реальных задач Chess.com приняты без ошибок. Отдельный тест на 90 сложных задачах содержит 319 ходов; 316 совпали с каноническим решением, одно из расхождений — другой немедленный мат. Есть настоящие промахи короткого расчёта. **Гарантии 90 задач за 5 минут нет.** Первый снимок не определяет рокировку/EP; для таких задач доступен ручной полный FEN.
