# nonchalant HUD · 0.1.3

Локальный шахматный HUD. Показывает «Есть блестящая идея» после проверки
кандидата настоящим Stockfish 19 Lite. Ход, фигура, оценка и варианты скрыты.
Жертва должна быть сильнейшим ходом на глубинах 20 и 22, с повторной проверкой
принятия и защиты. Предварительные результаты не вызывают уведомления.

## Что скачать на Windows

**[nonchalant-HUD-0.1.3-portable.exe](https://github.com/Rasher08/vukovic_chess_attack/releases/download/v0.1.3/nonchalant-HUD-0.1.3-portable.exe)** — основной вариант: открыть двойным
щелчком. Node.js, Python и отдельный Stockfish не нужны.

[nonchalant-HUD-0.1.3-setup.exe](https://github.com/Rasher08/vukovic_chess_attack/releases/download/v0.1.3/nonchalant-HUD-0.1.3-setup.exe) — тот же HUD с установкой и ярлыком.
Достаточно одного из этих файлов. Архивы **Source code** для обычного запуска
не нужны. Сборки предназначены для Windows 10/11 x64.

Готовые локальные файлы находятся в `hud/release/`. Опубликованные сборки —
на [странице релизов](https://github.com/Rasher08/vukovic_chess_attack/releases).
Номер версии указан в окне настроек и имени файла.

## Мини-гайд

1. Откройте `.exe` → **Ходы Chess.com → Открыть папку расширения**.
2. В Chrome откройте `chrome://extensions` → режим разработчика →
   **Загрузить распакованное расширение** → выберите открытую папку.
3. Обновите Chess.com. Скопируйте ключ из HUD, вставьте его в расширение
   на вкладке партии → **Подключить эту партию**.
4. HUD запоминает ходы по номерам и ждёт следующие. Настройки можно закрыть.

Если старые строки скрыты сайтом, они остаются в памяти. При подключении к
неполному списку один раз прокрутите запись к началу, затем в конец. Для новой
партии подключитесь заново. Обычное начало выбирайте только для стандартной
начальной расстановки; для своей позиции нужен FEN до первого записанного хода.

[Короткая инструкция](hud/QUICKSTART-WINDOWS.txt) ·
[Изменения 0.1.3 и ограничения](hud/RELEASE-0.1.3.md).

| Windows | Действие |
| --- | --- |
| Ctrl+Shift+P | Пауза |
| Ctrl+Shift+H | Свернуть / развернуть |
| Ctrl+Shift+M | Передвинуть / закрепить |
| Ctrl+Shift+N | Подтвердить новую стандартную партию в режиме картинки |

На Mac используется Cmd вместо Ctrl. Закреплённый HUD пропускает клики.
Настройки и выход доступны через значок в трее / строке меню.

Запасной режим **Доска на экране** работает по картинке. Для уже идущей партии
используйте **Позиция и ручная проверка**: вставьте полный
FEN из надёжного источника, загрузите его и подтвердите данные. Картинка не
определяет сторону хода, рокировки и en passant. Пропущенный ход или ошибка
распознавания могут потребовать повторного подтверждения. После изменения темы или
размера доски заново выберите область и обучите фигуры.

## Подключение к своему nonchalant

В HUD выберите **Из nonchalant**, скопируйте ключ и вставьте в меню **HUD**
в шапке локального сайта. Приложение передаёт полный FEN без распознавания
пикселей. Оставьте одну доску целиком видимой. После перезапуска подключитесь
снова. Ключ и позиции остаются на вашем компьютере.

## Из исходников

```sh
npm install
npm run hud:setup
npm run hud
```

Проверки: `npm run test:hud`. Полная партия: `npm --prefix hud run test:game`.
Сборка Windows: `npm --prefix hud run dist:win` (на Windows).

Проверены корректная и некорректная жертвы, размен, отмена устаревшего поиска,
восстановление движка и партия Ласкер — Бауэр в двух ориентациях.
[Отчёт проверки](hud/VERIFICATION.md) · [Подробная инструкция](hud/README.md).

Подтверждение использует критерии nonchalant; совпадение со значком Chess.com
не гарантируется. Проверка ограничена бюджетом и рассматривает не все виды
жертв. Отсутствие сигнала не доказывает отсутствие идеи.

Сборка тестовая: сквозной запуск расширения и EXE в настоящем Chrome на Windows
ещё не проверен. Разметка Chess.com может меняться. Анализ движком против людей
во время партии нарушает [Fair Play Chess.com](https://support.chess.com/en/articles/8568369-what-do-i-need-to-know-about-fair-play-on-chess-com)
и может привести к блокировке, даже если показывается только короткий сигнал.
