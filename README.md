# ♟️ nonchalant HUD

> **Локальный шахматный HUD-индикатор** для незаметного отслеживания глубоких тактических идей и блестящих ходов («!!») прямо во время игры.

HUD работает поверх любых окон, считывает позицию с доски и выводит **только один минималистичный сигнал**, если у стороны хода есть подтверждённая жертва или блестящая идея.

---

## 👁️ Главный принцип: Никакого читерского шума

HUD создан не для того, чтобы играть за вас первой линией движка, а чтобы тренировать тактическое чутье и вовремя подсказывать: *«Здесь есть скрытый тактический удар — остановись и посчитай!»*

- ❌ **НЕ показывает** сам ход, фигуру или координаты.
- ❌ **НЕ рисует** стрелки и варианты.
- ❌ **НЕ выводит** численную оценку позиции.
- ❌ **НЕ реагирует** на обычные лучшие ходы, взятия зевнутых фигур и стандартные размены.
- ✅ **Показывает ТОЛЬКО короткий сигнал**: `«Есть блестящая идея»` и знак `!!` при строгом подтверждении настоящей жертвы.
- ✅ При смене позиции сигнал **мгновенно исчезает**.

## 🚀 Быстрый старт

### Режим 1: Игра на Chess.com, Lichess и любых других сайтах (Распознавание экрана)

Этот режим захватывает выбранную область экрана с доской и на лету распознаёт расстановку фигур:

1. Запустите **nonchalant HUD**.
2. Откройте вкладку **«Распознавание экрана»**:
   - Нажмите кнопку **«Выбрать экран»** и укажите монитор, на котором открыта шахматная партия.
   - Нажмите **«Выбрать область доски»** и протяните рамку вокруг шахматной доски (минимальный размер — 256×256 пикселей).
3. **Калибровка фигур (один раз для стиля доски):**
   - Откройте на сайте стартовую позицию или вставьте FEN позиции.
   - Укажите ориентацию доски (*Белые* или *Чёрные* снизу).
   - Нажмите **«Обучить фигуры»**. HUD запомнит пиксельные маски фигур выбранного скина Chess.com/Lichess.
4. **Играйте:**
   - Встроенный фильтр стабильности (`FrameStabilityGate`) автоматически игнорирует кадры во время анимации перемещения или перетаскивания фигуры и дожидается статичной позиции.
   - При нахождении скрытой жертвы оверлей загорится бирюзовым цветом с надписью `«Есть блестящая идея»`.

#### Редактор и ручная проверка FEN:
В окне настроек доступна сетка 8×8 клеток и палитра фигур:
- Вы всегда можете нажать **«Исправить»**, кликнуть по любой фигуре на палитре и скорректировать распознанную клетку.
- Можно вручную задать сторону хода (`w`/`b`), права на рокировку (`KQkq`) и битое поле (`en passant`).

---

### Режим 2: Прямой мост (Direct Bridge) для nonchalant

Если вы занимаетесь в шахматном практикуме **nonchalant**, доступен прямой мост через локальный защищённый API:

1. В HUD переключитесь на вкладку **«Прямой мост»**.
2. Нажмите кнопку **«Скопировать ключ»**.
3. В приложении nonchalant вставьте токен в виджет подключения HUD.
4. Позиция будет передаваться моментально с точностью 100% без нагрузки на видеокарту и захвата пикселей экрана.

## ⌨️ Горячие клавиши и управление оверлеем

| Сочетание клавиш | Действие |
| :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>M</kbd> (Mac: <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd>) | **Режим перемещения**: позволяет перетащить полупрозрачный оверлей в любое место экрана. Повторное нажатие закрепляет HUD и включает сквозной пропуск кликов мыши по доске. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> (Mac: <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd>) | **Свернуть / Развернуть**: компактный режим значка (`!!`, `··`, `?`, `Ⅱ`) или развёрнутый информационный блок. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Mac: <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>) | **Пауза**: временно отключает поиск движка и гасит оверлей. |

Также управление доступно через контекстное меню иконки в **системном трее** (возле часов на Windows или в строке меню на macOS).

## 🎨 Индикация оверлея

- **Графитовый `··` / «Проверяется»** — позиция зафиксирована, Stockfish проводит глубокий многолинейный анализ (MultiPV).
- **Графитовый `!!` / «Проверено»** — проверка завершена, форсированных жертв и скрытых блестящих ходов не обнаружено (обычная игровая позиция).
- **Бирюзовый `!!` / «Есть блестящая идея»** — обнаружен кандидат на блестящий ход!
- **`?` / «Позиция не распознана»** — доска скрыта другим окном или изменился размер.
- **`Ⅱ` / «Пауза»** — анализ временно приостановлен.

---

## 🧠 Как работает проверка блестящего хода

HUD использует глубокий алгоритмический фильтр на базе **Stockfish 19 Lite**:

1. **Поиск возможных жертв:** движок оценивает линии ходов и проверяет наличие ходов с чистым вложением материала (от двух пешек) после прямого взятия.
2. **Проверка принятия жертвы:** отдельный расчёт лучшего ответа соперника при взятии пожертвованной фигуры.
3. **Сильнейшая защита:** проверка альтернативных опровержений жертвы.
4. **Исключение тривиальных ситуаций:** если позиция уже абсолютно выиграна (+8 и выше) и победа достигается любым простым разменом, сигнал **не выдаётся**, чтобы не засорять внимание ложными срабатываниями.
5. **Кэширование и отмена:** при появлении нового хода устаревший фоновый расчет немедленно отменяется, ресурсы процессора освобождаются.

## 🛠️ Запуск из исходников (macOS / Linux / Windows)

Если вы хотите запустить проект в режиме разработки:

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Rasher08/vukovic_chess_attack.git
cd vukovic_chess_attack

# 2. Установить зависимости веб-проекта и HUD
npm install
npm --prefix hud run setup

# 3. Собрать и запустить HUD
npm --prefix hud start
```

### Запуск тестов:
```bash
# Проверка типов
npm --prefix hud run typecheck

# 8 комплексных тестов детектора на настоящем Stockfish
npm --prefix hud test

# Тест растрового распознавания фигур
npm --prefix hud run test:raster

# Эмуляция запуска окон и моста
npm --prefix hud run smoke
```

### Сборка своего Windows .exe:
```bash
npm --prefix hud run dist:win
```
Собранные файлы будут лежать в папке `hud/release/`.

При первом запуске режима «Распознавание экрана» операционная система запросит разрешение на запись экрана:
