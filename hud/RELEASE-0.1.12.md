# Tal HUD Mentality 0.1.12 — время для сложных позиций

На каждый поисковый запрос Stockfish теперь получает до 15 секунд.
Глубина проверки остаётся 15: простая позиция завершается раньше, сложная
может считаться дольше 5–10 секунд. Предварительный отбор вариантов также
получает время на достижение нужной глубины.

Убраны прежние ограничения по числу узлов, которые могли завершить поиск
раньше нужной глубины. Недостаточная глубина по-прежнему не даёт сигнала.
Это не обязательная пауза на 15 секунд и не гарантия завершения любой позиции:
общий предел анализа остаётся 90 секунд, до 36 поисковых запросов.

Новый ход, пауза или потеря источника немедленно отменяют старый расчёт.
Пешечные жертвы остаются исключёнными; жертвы фигур и качества сохранены.

Для обновления завершите старый HUD через трей, установите setup.exe
и вставьте новый ключ подключения. Расширение менять не нужно.

Windows x64 EXE собраны на Mac. Установка на настоящей Windows локально
не проверялась.
