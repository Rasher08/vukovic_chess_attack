## Найденные и исправленные ошибки

- Загрузка сохранённых настроек происходила до инициализации переменных
  распознавателя. Исключение перехватывалось, настройки могли молча теряться.
  Инициализация перенесена; реальная перезагрузка окна проверена в smoke-тесте.
- Стартовая расстановка автоматически превращалась в полный начальный FEN,
  сбрасывая историю и метаданные. Теперь начало стандартной партии требует
  явного действия, а существующая калибровка сверяет расстановку с кадром.
  Первое обучение требует проверки редактора и подтверждения пользователем.
- Изменение масштаба 512 → 640 теряло уверенность в ферзе. Масштаб закреплён
  за калибровкой: старая калибровка отвергается, повторная успешно распознаёт
  доску. Порог уверенности ради этого не ослаблялся.
- Смена источника экрана теперь сразу отзывает позицию и требует подтверждения.
  Изменение области удаляет устаревшие шаблоны; явная калибровка сохраняет новые.
- Удалён диагностический вывод фигуры и клетки из распознавателя.
- Smoke-тест использует отдельное хранилище и свободный локальный порт, чтобы
  проверка не конфликтовала с обычным запущенным HUD.

## Пройденные команды

```sh
npm run test:hud
npm --prefix hud run test:game
npm --prefix hud run test:game:raster
npx tsc --noEmit
npm run test:auto
npm run test:review
npx tsx hud/tests/highlights.test.ts
```

Покрыты корректная жертва и её принятия, сильнейшая защита, игра чёрных,
некорректная жертва, обычный размен, отсутствие сигнала на обычной позиции,
перевёрнутая доска, перекрытие фигуры, смена масштаба, быстрые изменения позиции,
отмена устаревшего поиска, сбой/тайм-аут и восстановление новым процессом.

Smoke-тест проверяет настоящие окна Electron и цепочку локальный HTTP →
контроллер → Stockfish → короткий сигнал, затем немедленный отзыв сигнала.

## Оставшееся ограничение проверки

На этом Mac разрешение записи экрана для Electron имеет статус `denied`.
Живая запись экрана в этом прогоне не проверялась. Для неё нужно включить
Electron или приложение запуска в **Системные настройки → Конфиденциальность и
безопасность → Запись экрана и системного аудио**, затем перезапустить HUD.
Прямой мост из nonchalant этого разрешения не требует.

Запуск и остальные ограничения описаны в `README.md` этой папки.
