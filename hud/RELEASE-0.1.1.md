# nonchalant HUD 0.1.1 · тестовая версия

Для Windows x64 скачайте **nonchalant-HUD-0.1.1-portable.exe** и откройте его.
Установка, Node.js и отдельный Stockfish не нужны.
**setup.exe** — тот же HUD с установкой и ярлыком; достаточно одного файла.

## Как пользоваться

1. «Доска на экране» → «Выбрать экран» → выделить квадрат доски.
2. Указать цвет снизу. Открыть обычную стартовую расстановку.
3. «Начать новую партию» → сравнить фигуры → «Всё совпадает — запомнить».
4. Играть. Окно настроек можно закрыть.

**Ctrl+Shift+P** — пауза; **Ctrl+Shift+H** — свернуть;
**Ctrl+Shift+M** — переместить / закрепить.
Для идущей партии используйте «Позиция и ручная проверка» и полный FEN.

## Изменения

- Настройка в три шага, графитовый фон и бирюзовый акцент; номер версии в окне.
- Исправлены сохранение калибровки и отзыв позиции при смене источника.
- Метаданные FEN больше не назначаются автоматически по стартовой картинке.
- При смене масштаба требуется новая калибровка.
- Windows-сборки x64 со встроенным Stockfish 19 Lite; мини-гайд и SHA-256 рядом.

## Проверено и ограничения

Настоящий Stockfish: корректная/некорректная жертва, принятие жертвы, сильнейшая
защита, размен, отмена и восстановление. В партии Ласкер — Бауэр проверены
76 позиций: 73 завершены, 3 без достаточных данных оставлены без сигнала,
один кандидат подтверждён перед 15-м ходом белых. Все 152 растровых кадра партии
в двух ориентациях распознаны правильно.

Это тестовый релиз. Запуск `.exe` непосредственно на Windows и живая запись
экрана в этом прогоне не проверялись. В сборке нет цифровой подписи.
Распознавание зависит от темы и калибровки. Совпадение со значком Chess.com
не гарантируется; отсутствие сигнала не доказывает отсутствие идеи.
