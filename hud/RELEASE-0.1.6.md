# Tal HUD Mentality 0.1.6 — новое имя установщика и приложения

Название **Tal HUD Mentality** используется в Windows-приложении, установщике,
ярлыках рабочего стола и меню «Пуск», списке установленных программ, окне
настроек и трее. Файл установки — `Tal-HUD-Mentality-0.1.6-setup.exe`.

Поиск корректных жертв, собственная музыка и расширение работают как в 0.1.5.
Для сохранения настроек оставлены прежние идентификатор установки и каталог
профиля. Переименование не создаёт новый пустой профиль. Старые версии и новая
используют общий single-instance lock.

Закройте прежний HUD через значок в трее и запустите новый setup. Для ранее
установленной версии используется тот же идентификатор обновления; настройки
и аудиофайлы остаются в прежнем пользовательском каталоге. После запуска
обновите ключ подключения в расширении; переустановка расширения не требуется.

Сборка создана локально на Mac; её запуск и обновление установленной версии
в настоящей Windows этим прогоном не проверены. GitHub-релиз не публиковался.
