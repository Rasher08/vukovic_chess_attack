# Tal HUD Mentality 0.1.8 — галочки для музыки и одна глубина 22

В библиотеке галочками выбираются только нужные треки: например, три из десяти.
Один отмеченный играет сам, несколько выбираются случайно только из отмеченных.
У стандартного сигнала отдельная галочка; её можно снять. Пустой выбор означает
тишину. Удаление последнего отмеченного трека не включает другой звук.
Выбор сохраняется после перезапуска, библиотека из прежней версии переносится.

HUD выполняет один проход проверки на глубине 22 вместо повторения на 20 и 22.
Сохраняются проверка качества самой жертвы, всех способов её принятия и лучшей
независимой защиты. Сигнал не показывается до окончания этих поисков и при
недостаточной глубине. Предварительный поиск кандидатов не считается проверкой.
Это не обещание фиксированного времени: сложная позиция может считаться дольше.

В локальном сравнении на позиции 24…Bxf2+ из присланной партии: 20+22 — 8,7 с,
только 22 — 7,0 с. На других позициях выигрыш времени отличается; некоторые
отрицательные позиции при одной22 считаются дольше. Подробности — в
[сравнении глубин](DEPTH-COMPARISON.md).

Перед обновлением завершите старый HUD через значок в трее и запустите setup.
Музыка и настройки сохраняются. **Новое расширение скачивать не нужно**:
после запуска HUD вставьте новый ключ в уже установленное расширение.

EXE собраны локально на Mac. Запуск установщика на настоящей Windows локально
не проверялся. Контрольные суммы поставляются в SHA256SUMS-0.1.8.txt.
