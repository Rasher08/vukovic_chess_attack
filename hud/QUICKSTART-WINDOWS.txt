Tal HUD Mentality 0.1.8 — Windows 10/11 x64 · Chrome

Запустите Tal-HUD-Mentality-0.1.8-setup.exe: он установит приложение
и создаст ярлыки Tal HUD Mentality. Portable доступен отдельно без установки.
Команды, Node.js и отдельный Stockfish не нужны.

ОБНОВЛЕНИЕ С 0.1.2 / 0.1.3 / 0.1.4 / 0.1.5 / 0.1.6 / 0.1.7
Значок HUD в трее возле часов → «Завершить HUD». Затем откройте новый EXE
и вставьте новый ключ в расширение. Крестик окна только скрывает настройки.
Уже установленное расширение 0.1.2 совместимо; переустанавливать его не нужно.

ОДИН РАЗ
1. HUD → «Ходы Chess.com» → «Открыть папку расширения».
2. В адресной строке Chrome: chrome://extensions
3. «Режим разработчика» → «Загрузить распакованное расширение».
4. Выберите папку из первого шага. Обновите страницу Chess.com.

ПОДКЛЮЧИТЬ ПАРТИЮ
1. В HUD нажмите «Скопировать ключ».
2. На вкладке Chess.com откройте расширение nonchalant (значок пазла в Chrome).
3. Вставьте ключ → «Подключить эту партию».
4. HUD покажет число запомненных ходов. Окно настроек можно закрыть.

Ходы запоминаются по номерам. Поворачивать и масштабировать доску можно.
Если начало списка скрыто: прокрутите к первому ходу один раз, затем в конец.
При просмотре старых ходов HUD ждёт возвращения к последнему.
После начала новой партии подключите её заново. Ключ сохраняется в расширении
до перезапуска Chrome; после перезапуска HUD скопируйте новый ключ.
Обычное начало выбирайте только для обычной начальной расстановки.
Для партии из своей позиции укажите полный FEN до первого записанного хода.

Сигнал: только «Есть сильная жертва». Ход, оценка и варианты не показываются.
Он появляется после одной проверки на глубине 22. До этого — «Проверяется».
HUD сообщает о жертве в текущей позиции; сыгранный вами ход может быть другим.
Если сигнал кажется ошибочным: настройки → «Если сигнал выглядит ошибочным»
→ «Скопировать диагностику». Вставьте полученный текст в сообщение для проверки.
Профиль ищет корректную жертву с достаточной компенсацией, а не значок Chess.com.
Ей не обязательно быть первым выбором движка; другие хорошие ходы не мешают.
Проверяются пешечные жертвы, жертвы качества и фигур от одной пешки вложения.
Компенсация — конечная оценка движка, а не доказанная ничья.
Использование анализа движка против людей во время партии нарушает Fair Play
Chess.com и может привести к блокировке аккаунта. Гарантии незаметности нет.

СВОЯ ФРАЗА ИЛИ МУЗЫКА
1. «Звук уведомления» → «Добавить свои файлы…»: можно сразу несколько.
2. Галочками отметьте нужные треки (хоть 3 из 10). Снимите «Стандартный сигнал».
3. Длительность: 1–600 секунд либо «До конца трека».
4. По желанию включите «Останавливать музыку после сделанного хода».
5. «Прослушать» → громкость. Для уведомлений включите «Звук» вверху.

Один отмеченный звук играет сам; несколько — случайный выбор только из них.
Ни одного отмеченного — тишина. Стандартный тон включается отдельной галочкой.
Готовых треков нет: пользователь добавляет свои локальные файлы.
MP3/WAV/OGG/M4A/AAC/FLAC: до 12 МБ каждый, до 20 файлов и 120 МБ суммарно.
«Стоп» — прекратить звук; «Удалить» возле трека — убрать один трек из HUD.
«Стандартный сигнал» — вернуть короткий тон, сохранив свою библиотеку.
Файлы и настройки сохраняются; музыка из предыдущей версии переносится.
Без остановки после хода трек доигрывает при следующих позициях. Пауза,
выключение звука и потеря источника останавливают музыку. Новые уведомления
не накладывают второй звук поверх играющего. Короткие файлы не зацикливаются.
Ссылки YouTube и плейлисты Яндекс Музыки не подключаются: нужен аудиофайл.

Ctrl+Shift+P — пауза.
Ctrl+Shift+H — свернуть HUD.
Ctrl+Shift+M — передвинуть / закрепить HUD.
Ctrl+Shift+N — подтвердить начальную расстановку (только режим картинки).

Настройки и выход — значок HUD в трее возле часов.
Распознавание картинки остаётся отдельным запасным режимом «Доска на экране».
Там для уже идущей партии: «Позиция и ручная проверка» → полный FEN.
После смены размера доски или темы заново выберите область и обучите фигуры.
Текстовый режим не требует разрешения на запись экрана.
