# Tal HUD Mentality 0.1.7 — своя музыкальная библиотека

Пользователь добавляет один или несколько своих аудиофайлов. Готовых музыкальных
треков нет. Можно выбрать конкретный файл либо случайный трек из библиотеки,
установить длительность 1–600 секунд либо воспроизведение до конца и отдельно
настроить остановку после сделанного хода.

В библиотеке до 20 файлов, до 12 МБ каждый и до 120 МБ суммарно. Файлы проверяются
перед добавлением и копируются в локальное хранилище. Повреждённый файл не мешает
добавить исправные. Случайный выбор происходит заново при уведомлении, повторы
возможны. Новый сигнал не перезапускает и не накладывает ещё один играющий трек.
Короткая запись не зацикливается.

При выключенной остановке после хода музыка продолжится через следующие
корректные позиции. Пауза, выключение звука, смена источника и недоступная позиция
останавливают воспроизведение. «Стандартный сигнал» сохраняет библиотеку;
«Удалить выбранный» удаляет только один файл из HUD.

Старый одиночный трек и настройки сохраняются при обновлении. Идентификатор
установки и каталог пользовательского профиля прежние. Завершите старый HUD
через значок в трее, затем запустите Tal-HUD-Mentality-0.1.7-setup.exe.
Расширение менять не нужно; после запуска обновите ключ подключения.

Сборка создана локально на Mac. Запуск и обновление на настоящей Windows этим
прогоном не проверены. Готовые EXE опубликованы в GitHub Releases.
