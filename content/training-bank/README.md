# Дополнительный банк: 480 позиций

Источник: https://database.lichess.org/lichess_db_puzzle.csv.zst — CC0. Получено 24 октября 2026 года. Полные чужие аннотации и имена игроков не импортировались; сохранены фактические позиции/ходы и URL исходной партии.

`selected-source-rows.json` — канонические 480 строк, обеспечивающие точное воспроизведение текущего банка. `selection-report.json` фиксирует фильтры и квоты. Отбор выполнялся в два прохода: для матовых сетей квота высокой рейтинговой полосы оказалась слишком редкой, поэтому остаток заполнен подходящими задачами других полос. Это не случайная или репрезентативная выборка.

Фильтры: 2200–2800 Lichess Puzzle; RatingDeviation<=85; Popularity>=85; NbPlays>=500; middlegame, без endgame/mateIn1/mateIn2; 6–18 исходных полуходов, включая установочный ход соперника; разные исходные партии. Фактический диапазон 2201–2791. Рейтинг задач не сравнивается с игровым Chess.com.

В каждой из шести областей 80 позиций. SHA-256 по стабильному идентификатору детерминированно выделяет по 16 в контроль, остальные 64 — обычная практика. Всего 384/96; источник партии не повторяется между областями и контрольными наборами.

Сборка: `npm run build:training-bank`. Она применяет первый UCI-ход соперника к исходному FEN (требование формата Lichess), конвертирует оставшееся решение в SAN, проверяет легальность и уникальность. 3502 перехода с установочными ходами, 3022 полухода собственно решений. `npm run test:training` проверяет банк, интервалы и сохранение прогресса.

Объяснение каждой задачи содержит только вычислимые факты: тип первого хода, первый ответ, исходную ветку и материальный баланс. Этот текст не выдаётся за авторскую глубокую аннотацию позиции. Теги исходной базы определяют область; результат отдельной ручной проверки всех 480 позиций не заявляется.

Для нового отбора: `curl -L https://database.lichess.org/lichess_db_puzzle.csv.zst | zstd -dc | python3 scripts/import_training_bank.py`. Скрипт завершает чтение после набора квот, поэтому upstream curl может сообщить о закрытом pipe. Для точного текущего банка используйте уже сохранённые selected-source-rows.json, поскольку публичная база обновляется.

Защита в точных узлах исходного решения берётся из подготовленной линии базы. Любое отклонение вызывает поиск по фактическому FEN (Stockfish Lite, 1 500 000 узлов). Итоговая оценка — 1 000 000 узлов на поиск. Это ограниченный анализ, не гарантия единственности решения.
