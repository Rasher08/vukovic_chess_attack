# Материалы авторского практикума

Курс следует 12 темам оглавления Art of Attack in Chess. Теория написана заново. Это не полный текст и не оцифровка книги. Только партия Керес — Решевский, 1948, подтверждена как пример главы 9 по опубликованному издательскому фрагменту ChessPro; прочие партии — самостоятельный дополнительный подбор.

## Источники

- Оглавление: https://www.perlego.com/book/5299582/the-art-of-attack-in-chess-pdf
- Издательское описание: https://www.newinchess.com/art-of-attack-in-chess
- Русский издательский фрагмент: https://chesspro.ru/books/vukovich_iskusstvo_ataki_v_shahmatah
- PGN исторических партий: https://www.pgnmentor.com/files.html (архивы игроков, скачаны с User-Agent Mozilla/5.0). Здесь сохранены только использованные партии, не полные архивы игроков.

## Воспроизведение

Нужен Python с пакетом python-chess и официальный исполняемый Stockfish. Бинарник не включён в проект.

1. `python content/course-build/generate_theory.py` обновляет `chapters.json`.
2. При необходимости повторного расчёта: `STOCKFISH_BINARY=/absolute/path/to/stockfish python content/course-build/refine_lines.py`.
3. `python content/course-build/generate_course.py` собирает `src/data/course.ts` из локальных исходных материалов.
4. `npm run validate:course` проверяет все переходы через chess.js.
5. `npm run audit:course -- /absolute/path/to/stockfish 2500000` выполняет независимый аудит первых ходов.

`analyses.json` содержит обзор трёх кандидатов на 700 000 узлов и отдельную проверку выбранного первого хода. `refined.json` содержит выбранную ветку после поиска на 2 500 000 узлов, Threads=1, Hash=128 MiB; PV при необходимости продолжена отдельным поиском на 700 000 узлов. Учебные линии сокращены до содержательного конечного узла; полный расчёт сохранён в отчёте. `accepted.json` хранит отдельно проверенные альтернативные планы Rd5 и Kd2. Последний вариант дополнен двумя легальными ходами размена на d2 из независимого аудита.

Линии исторической партии помечены `accepted: false`: они показывают фактическую игру, но не гарантируют лучшую защиту. Эталонные варианты не доказывают уникальность решений и не заменяют безлимитный анализ. Численный рейтинг сложности задач не присваивался. Упражнения на известных комбинациях проверяют более упорные защитные ветки. Двадцать задач покрывают программу, но не исчерпывают книгу или все формы атаки.

В дополнительных контрольных поисках на 1 500 000 узлов подтверждены: преждевременное Bxh7+ в позиции до 14.Nh5 опровергается Nxh7; Rd7+ вместо 36.Bf1 проигрывает после Rxd7 и Qxf1. Полные доступные ветки этих опровержений включены в course.ts.
